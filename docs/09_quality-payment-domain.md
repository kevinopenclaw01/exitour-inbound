회의 결정 흐름("예약 요청 → 사람이 확정 → 결제 링크")과 회의 조건("실결제는 법 확인 뒤", "실결제 3팀으로 수요 확인")에 맞춘다.

**1단계 — 첫 실결제 3팀까지: PayPal 결제 링크(인보이스) 수동 발송**
- 코드 변경 없음. 확정 메시지에 PayPal 인보이스 링크를 붙여 보낸다. 손님은 PayPal 계정 또는 카드로 결제(게스트 결제 가능 여부는 손님 나라에 따라 다름)
- 장점: PG 심사·사이트 약관 페이지 없이 바로 시작, 외국인에게 익숙함
- 단점: 4.4% + 0.30 USD + 환전 3%로 실제 부담이 7% 안팎까지 갈 수 있다. USD로 받으면 환전 손실을 줄이려면 USD 잔액을 모았다가 출금
- 금액은 **선금(예: 30%)만** 받을지 전액 받을지 사장님 결정(6장 결정 5)

**2단계 — 상시 판매: 국내 PG 해외카드 + 사이트 결제 페이지**
- 1순위 후보 **토스페이먼츠 해외카드**(4.5%, KRW 정산, 결제위젯에 PayPal 같이 붙임, 개발 문서·지원이 좋다). 비교 견적으로 **나이스정보통신(3.8%)** 도 받는다
- 엑심베이는 Alipay·WeChat이 필요해질 때(중화권 손님) 추가. 시작 한도 월 USD 1,000이라 첫 PG로는 맞지 않는다
- 사이트 구현: `inquiries`에 금액·상태가 정해지면 `/pay/[요청번호]` 결제 페이지 → 결제 완료 웹훅으로 `status = booked`(새 `payments` 테이블, 마이그레이션 파일로). 카드 정보는 PG 화면에서만 입력되고 우리 서버·DB에 남지 않는다
- **PG 심사 전에 필요한 것**: 1장 Q1·Q2(약관·개인정보처리방침·환불 규정·사업자 정보), 통신판매업 신고번호, 도메인(5장). 여행업 PG는 선수금 성격이라 보증보험·정산 보류 조건을 요구할 수 있다 → 상담 때 확인

**병행 — OTA 1곳(Viator)**: 회의 결정. 결제·환불·노쇼를 OTA가 처리해 첫 손님 리스크가 적다. 수수료가 크므로 직판 가격과 OTA 가격 정책을 같이 정한다.

**쓰지 않을 것**: Stripe(가입 불가), 해외 법인 우회(세무·외환 문제를 새로 만든다).

### 4-3. PG 상담 때 물어볼 것

1. 여행업(외국인 대상 국내 투어) 해외카드 입점 가능 여부, 선수금 관련 보증·정산 보류 조건
2. 해외 발급 카드 **Apple Pay·Google Pay** 지원 여부와 수수료
3. 결제 링크(링크페이)로 해외카드 결제가 되는지 — 되면 2단계 전에도 코드 없이 쓸 수 있다
4. 정산 주기·통화(KRW/USD), 부분 환불·차지백 처리
5. 해외카드 3DS 인증 실패율과 대응(인증 실패는 외국인 결제 이탈 1순위)

### 5-1. 조회 결과 (2026-10-28, 레지스트리 RDAP 조회 — 등록된 도메인으로 조회 방식 검증함)

| 도메인 | 상태 |
|---|---|
| **entourkorea.com** | 미등록(구매 가능으로 보임) |
| entour-korea.com | 미등록 |
| goentourkorea.com | 미등록 |
| entourtravel.com, entourtours.com | 미등록 |
| entour.com | **이미 등록됨** |
| **entour.kr**, entourkorea.kr, entour.co.kr | 미등록 |
| entour.travel, entourkorea.travel | 미등록 |
| entourkorea.co | 이 방법으로는 확인 불가 |

RDAP "미등록"은 레지스트리에 없다는 뜻이다. 프리미엄·예약 도메인일 수 있으므로 최종 가격은 구매 화면에서 확인한다.

### 5-2. 추천

1. **본 도메인: `entourkorea.com`** — 브랜드 + "korea" 검색어, 외국인이 가장 믿는 .com, 하이픈 없음. 10-13 회의 때 Vercel 조회로 일반 .com이 등록·갱신 각 11.25 USD였다(참고값)
2. **방어용(선택): `entour.kr`** — 짧고 한국 업체임이 드러난다. 사지 않아도 운영에는 지장 없다. 사면 본 도메인으로 넘기기만 한다
3. 피할 것: `.travel`·`.tours` — 10-13 회의 기록상 갱신비가 높다(exitour.travel 갱신 129.47 USD, exitour.tours 갱신 66.73 USD). `.co`는 .com 오타로 손님이 다른 곳에 갈 수 있다

구매처: Cloudflare Registrar(원가 판매, 갱신 인상 없음) 또는 Vercel Domains(배포와 같은 곳, 연결이 쉬움). 도메인을 산 뒤:
- Vercel 프로젝트에 연결, 환경변수 `NEXT_PUBLIC_SITE_URL=https://entourkorea.com`
- 이메일 `hello@entourkorea.com` 같은 주소를 만든다(Cloudflare 이메일 라우팅은 무료 전달, 보내기까지 하려면 Google Workspace 등) → `site.ts`의 `email`
- 구글 서치콘솔·Bing 웹마스터 등록(handoff E)

### 5-3. 이름 확인 남은 것

- 웹 검색에서 "Entour Korea"·"Entour Travel"이라는 여행사는 찾지 못했다
- **특허청 KIPRIS 상표 검색은 하지 않았다**(사람이 확인). 여행업 분류(제39류)·여행 안내(제41류)에 "Entour/엔투어"가 있는지 보고, 없으면 출원을 검토한다. 결정 기록 2026-10-24 1번도 "도메인·상표 확인 전"으로 남아 있다
