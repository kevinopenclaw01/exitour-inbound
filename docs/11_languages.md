# 11. 다국어(2026-11-16)

사장님 지시 「언어를 중국어, 일본어, 스페인어, 인도네시아어, 태국어, 필리핀 따갈로그, 베트남어 추가해서 만들어줘」로 영어 외 7개 언어판을 붙였다.

## 1. 주소

| 언어 | 주소 | `<html lang>`·hreflang |
|---|---|---|
| 영어 | `/`, `/prices` (앞머리 없음, 예전 주소 그대로) | `en` |
| 중국어(간체) | `/zh`, `/zh/prices` | `zh-Hans` |
| 일본어 | `/ja/...` | `ja` |
| 스페인어 | `/es/...` | `es` |
| 인도네시아어 | `/id/...` | `id` |
| 태국어 | `/th/...` | `th` |
| 따갈로그(필리핀) | `/tl/...` | `tl` |
| 베트남어 | `/vi/...` | `vi` |

- 쪽 파일은 모두 `src/app/[lang]/` 아래에 있다. `src/proxy.ts`가 앞머리 없는 영어 주소를 안쪽 `/en/...`으로 넘긴다(주소창은 그대로). `/en/...`으로 들어오면 앞머리 없는 주소로 308 이동한다.
- 빌드 때 8개 언어의 모든 쪽을 미리 만든다(`app/[lang]/layout.tsx`의 `generateStaticParams`).
- 쪽마다 `<link rel="alternate" hreflang>` 8개 + `x-default`(영어)가 들어간다. 사이트맵도 언어마다 주소를 싣고 서로 묶는다.
- 머리글 오른쪽의 언어 단추(지구 모양)로 같은 쪽의 다른 언어로 간다. 바닥글에는 언어별 첫 화면 링크가 있다.
- **영어판만 있는 쪽**: 약관·개인정보·환불(아직 초안, 변호사 검토 전)과 숨긴 쪽(`/guide-tour`, `/join-as-guide`). 다른 언어 주소는 404다(`src/lib/meta.ts`의 `englishOnlyPages`, 쪽 맨 위의 `await englishOnly()`).
- 공유 그림(`/og/...png`)은 영어판 하나를 모든 언어가 같이 쓴다. 그림을 굽는 글꼴에 한자·태국 문자가 없어서다.
- `llms.txt`는 영어로 두고 끝에 언어판 목록만 붙였다.

## 2. 번역이 들어 있는 곳

| 파일 | 내용 |
|---|---|
| `src/i18n/config.ts` | 언어 목록, 주소 규칙(`localizePath`, `splitLang`) |
| `src/i18n/translate.ts` | 번역 함수 `t`. 사전의 열쇠는 **영어 원문 그대로**다. 사전에 없으면 영어가 나온다(화면이 깨지지 않는다) |
| `src/i18n/server.ts` | 서버 조각에서 `const t = await getT()` |
| `src/i18n/messages/<언어>.json` | 7개 언어 사전(영어 원문 → 번역) |
| `src/i18n/source.json` | 번역할 영어 문장 전체 목록(자동 생성) |
| `src/i18n/extract.ts` | 위 목록을 코드(`t("…")`·`t.rich("…")`·`msg("…")`)와 콘텐츠 자료에서 모으는 규칙 |
| `src/i18n/formStrings.ts` | 여행 요청 폼(브라우저 쪽)에 넘기는 문장 목록 |

콘텐츠 자료(`src/content/*.ts`)는 영어 그대로 두고, 화면에 낼 때 `t.obj(자료)`로 통째로 바꾼다. 가격 문장(`src/lib/pricing.ts`)과 값 FAQ(`src/lib/productFaqs.ts`)는 번역기를 받아 그 언어로 만든다.

여행 요청은 어느 언어에서 보내도 **저장 값과 사장님께 가는 알림은 영어**다(상품 이름, "어떻게 알게 되셨나요" 값). 손님이 입력한 글은 손님 언어 그대로 온다.

## 3. 영어 문장을 바꾸거나 더할 때(중요)

1. 영어를 고친다. 화면 조각 안의 문장은 `t("…")`로 감싸고, 쪽 위쪽 상수처럼 바로 감쌀 수 없으면 `msg("…")`로 표시한다. 문장 안의 값은 `t("Up to {n} passengers", { n })`처럼 자리 표시로 넣는다(문자열을 이어 붙이지 않는다).
2. `npm.cmd test`를 돌린다. 내 PC에서는 `src/i18n/source.json`이 새로 쓰이고, **7개 언어 사전에 빠진 문장**이 시험 실패로 나온다(CI에서는 목록이 낡았으면 실패).
3. 빠진 문장을 7개 사전에 채운다. 자리 표시 `{…}`와 태그 `<…>`는 원문과 같아야 한다(시험이 확인한다). 검색 설명(쪽 description)은 155자 이하.
4. 영어만 고치고 사전을 안 채우면 그 문장만 영어로 나온다. 고친 원문과 다른 옛 번역은 쓰이지 않는다(열쇠가 원문이라서). 시험이 실패하므로 그대로 배포되지는 않는다.

## 4. 번역 품질

- 2026-11-16 번역은 **AI 초안**이다(Claude가 언어별로 따로 번역하고 자리 표시·길이·용어를 기계 검사함). `docs/04`의 원칙대로 **원어민(가이드·손님) 검수**를 한 번 받는다. 검수자가 고친 것은 그 언어의 `messages/<언어>.json`에서 값만 바꾸면 된다.
- 지명은 그 언어 독자가 아는 표기(중국어 首尔·南怡岛, 일본어 ソウル·南怡島 등)를 썼다.
- 사실을 더하거나 빼지 않았다. 특히 "가이드가 손님 언어로 안내한다"는 말은 어느 언어판에도 없다. 지금 안내 언어는 영어뿐이다(`site.guideLanguages`). 여행 요청 쪽에만 "자기 언어로 써도 된다, 답은 영어나 번역 앱으로 한다"는 한 줄을 다른 언어판에 넣었다.
- 언어별 용어 선택(Driver only, Driver-guide, 자격 가이드 등)은 이 문서 5장.
