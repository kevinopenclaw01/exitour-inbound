## 2026-10-24

1. **외국인용 브랜드는 "Entour Korea", 운영사는 Exitour** — Exitour(한국인이 세계로 나감, exit)의 반대 방향(외국인이 한국에 들어옴, enter)이고, entourage(나만의 기사·가이드 일행)라는 뜻도 있다. 사이트에는 "by Exitour"와 종합여행업 등록을 함께 표시해 신뢰를 준다. 도메인·상표(KIPRIS) 확인은 아직 하지 않았다. 다른 후보: Hanroute, Exitour Korea. — 사장님 요청으로 Claude가 제안 (사장님 확정 대기)
2. **특정 국가를 목표로 정하지 않는다** — 마케팅은 인스타·유튜브·틱톡과 AI 검색이 중심이라 국가는 키워드 차이일 뿐이다. 사이트는 영어로 시작하고, 다른 언어 페이지는 실제 문의가 들어오는 순서대로 추가한다. — 사장님
3. **핵심 서비스 3종을 먼저 만들고, 개별 투어 상품은 그다음에 만든다** — 개별 상품부터 만들면 상품 만들다 끝난다. — 사장님
   - 차량 + 기사(운전만)
   - 차량 + 가이드(자격 있는 기사 겸 가이드, 또는 기사와 가이드 따로)
   - 가이드 투어(차량은 옵션). 여행 상담과 일정 설계를 포함한다. 노을 갈매기, 한강 팩은 이 서비스 안의 설계 예시다
4. **저장 위치는 비공개 GitHub 저장소 `exitour-inbound`, PC에서는 `C:\AI\exitour-inbound`** — 넥서스(`C:\AI\llm-hub`)는 허브 앱이라 섞지 않는다. 넥서스 코딩 탭은 돌고 있는 허브 폴더를 작업 폴더로 쓸 수 없다. 기존 `exitour-platform`은 **공개 저장소**라 원가가 담긴 문서를 둘 수 없고, 고객층(한국인)·언어·브랜드도 다르다. 기술은 같은 계열(Next.js 16 + Supabase)로 맞춰 나중에 DB와 관리자 기능을 함께 쓸 수 있게 한다. — Claude 제안
5. **AI 검색 노출이 마케팅의 핵심** — 사이트는 "정답 원본"이 되고, 유튜브·레딧·트립어드바이저·OTA·블로거가 이를 반복해서 언급하게 만든다. — 사장님
